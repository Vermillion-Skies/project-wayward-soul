Wayward Soul
============
A text based RPG built in Python 3 with Toga for the UI, and packaged in Briefcase for distribution across many Linux distros, Windows, MacOS, and Android. Proudly written with no AI, just me writing code and making up a story as I go.
------------

INSTALLING
============
IMPORTANT NOTE FOR ALL OPERATING SYSTEMS
------------
None of these installs are signed, at least I don't think they are. If you see a security warning pop up, just ignore that. If you don't trust me (which is fair tbh) look through my code. All of this is open source. If you don't trust me and want to build it yourself, then go for it. Also, some OS builds are untested due to me not having access to the hardware needed. I'm a college student, I can't afford a good laptop AND a Mac on top of that.

Windows
------------
1. Download the .msi file from the latest release
2. Run the installer

MacOS (untested)
------------
1. Download the .dmg file from the latest release
2. Open the dmg file and drag WaywardSoul into your applications folder
3. Authenticate if needed

Arch-based Linux (Arch, Manjaro, SteamOS (I guess???))
------------
1. Download the .pkg.tar.zst file from the latest release
2. Enter a terminal and CD into the directory you downloaded the file to
3. Run sudo pacman -U *filename*.pkg.tar.zst

Debian-based Linux (Ubuntu, Linux Mint, Debian) (untested for now)
------------
1. Download the .deb file from the latest release
2. Enter a terminal and CD into the directory you downloaded the file to
3. Run sudo apt install ./*filename*.deb

Red Hat-based Linux (Fedora, RHEL, CentOS, Alma) (untested for now)
------------
1. Download the .rpm file from the latest release
2. Enter a terminal and CD into the directory you downloaded the file to
3. Run sudo rpm -ivh *filename*.rpm
